# Telos — Gestão Financeira (versão didática)

Programa de console em Java, em **um único arquivo** (`Main.java`), escrito para ser explicado de cima para baixo.

Autores: Warley Rocha Santos, Kauã Gabriel Lopes Catrinck, Marcus de Moraes Oliveira, Eduardo Ayres de Carvalho Cruz e João Victor de Melo Costa.

## Como executar (Java 8 ou superior)

```
javac Main.java
java Main
```

No IntelliJ: abra a pasta, clique com o botão direito em `Main.java` e escolha **Run 'Main.main()'**.

## Ordem do arquivo
1. Constantes  2. Modelos (Lancamento e Orcamento)  3. Dados (listas)  4. Programa principal (menu)
5. Funções do menu  6. Funções de apoio (cálculos e textos)  7. Leitura segura do teclado
